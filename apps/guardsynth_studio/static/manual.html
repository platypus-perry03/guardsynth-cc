영상과 시점 선택

로그인 후 영상을 선택하세요. 추출 목록의 간격과 시점 수로 원하는 자료를 구분합니다. 왼쪽 영상 아래 CAN이 표시됩니다. 썸네일이나 슬라이더로 시점을 이동할 수 있습니다.

1. CoC 생성

현재 시점까지의 영상과 CAN으로 실제 행동의 설명을 생성합니다. 왼쪽은 모델 원문, 오른쪽은 수정 문장입니다. 수정하지 않았다면 ‘수정 없이 모델 제안 수용’을 체크하고 ‘검토 완료 · 다음’을 누르세요. 수정한 내용은 자동 저장됩니다.

2. 제약 사항 생성

CoC를 검토한 뒤 제약을 생성하세요. 조건 설명을 수정할 수 있고, 발동·유지·해제 근거는 펼쳐서 확인할 수 있습니다. 수정하지 않았다면 수용 체크 후 다음 단계로 이동하세요.

3. EBLC 생성

검토한 제약을 EBLC Core 정형 표현으로 자동 변환합니다. 직접 작성할 항목은 없습니다.

4. 검증

생성한 정형 표현으로 개별 시점과 이어지는 시점의 조건을 검사합니다. 해제 근거 없이 이전 조건이 사라지거나, 유지 중인 조건과 행동이 맞지 않는 경우 등을 확인합니다. 규칙 출처 또는 관찰이 미확인이면 확인 필요로 남깁니다.

5. CNL 생성

검증한 제약을 정해진 문장 형식으로 보여줍니다. 확인 필요 또는 모순 결과도 문장에 표시됩니다. 이 문장은 검토용이며 학습 자료 승인이나 사고 없는 운전을 증명하지 않습니다.

앞 단계를 수정했다면

CoC나 제약을 바꾸면 뒤 단계는 다시 실행해야 합니다. 모델 호출은 CoC와 제약 생성 버튼을 누를 때만 사용됩니다. EBLC 생성·검증·CNL 생성은 추가 모델 호출 없이 실행됩니다. 다른 창의 수정과 충돌하면 내 초안과 최신 내용을 비교할 수 있습니다.
