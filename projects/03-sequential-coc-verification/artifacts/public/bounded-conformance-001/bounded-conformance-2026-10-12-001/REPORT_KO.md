# 유한 사건열 전수 적합성 시험

고정한 두 모델의 실제 XML에서 step 함수를 변경 없이 추출하여 C++로 실행했다. 별도 판정기는 전체 접두열에서 최근 증거ㆍ의무 생성과 과거 해제를 직접 계산하며 상태 갱신 함수를 공유하지 않는다. 생성은 유한 직적의 전수 열거로 기대 결과에 따른 사례 선별이 없다.

| profile | 사건열 수 | 불일치 |
|---|---|---|
| condition-k1-n3 | 378,504 | 0 |
| condition-k2-n3 | 34,117,524 | 0 |
| boundary-k1-n3 | 348,504 | 0 |
| boundary-k2-n2 | 198,396 | 0 |
| p4-sticky-release-control | 5,256 | 1,884 |

주 시험 총 35,042,928건, 불일치 0건. 마지막 행은 주석 오류가 아닌 의도적 P4 처리 고장 대조군이며 주 시험 분모에 합산하지 않는다. 모든 불일치는 별도 JSONL에 보존했다. 첫 경계 없음, 의무 1/2개, 길이 상한과 세부 알파벳은 protocol.json에 고정했다. YIELD는 현 IR의 STOP과 같은 비진행 코드로 투영된다. P2의 별도 해제 명령은 인터페이스에 없어 평가하지 않는다.

UPPAAL 탐색기를 새로 실행한 시험은 아니며 실제 XML의 이산 step 의미를 수식 판정과 비교한 native 적합성 시험이다. 기존 144건/81건의 실제 verifyta 실행과 구분한다. 같은 연구 작성자가 두 경로에 관여했으므로 외부 독립 정답이나 명세의 현실 타당성을 입증하지 않는다. R3-7의 사례 선별 순환성에 대한 구조적 부분 대응이며 자연 의미 평가·독립 작성 역할의 한계는 남는다.
