# 절별 기존/개정 비교와 후속 보강

비교 기준은 원 저장소10쪽 제출본이며, E6 완료 직후8쪽 소스를 별도 보존했다. 글자 수나 페이지 수를 목표로 삼지 않고 유효한 방법 설명과 해석을 확인했다.

- 01-introduction.tex: 핵심 동기와 A/B 예시, 연구 질문·기여 유지. 상세 절차는 방법 절로 배치하고 마지막 반복 범위 문단은 구조 안내로 정리. 장황한 원 제출본 서론은 복원하지 않음.
- 02-related-work.tex: E6에서 보완한 RV/LTL 및 기술 비교를 유지하고 조건 ID 대응의 기술적 접점을 설명. 최초/최고/우월성 주장과 검증하지 않은 인과 충실성 주장은 복원하지 않음.
- 03-data.tex: 기록값·계산값·자동 주석·검사 정의의 구분, 사후 생성 흐름 도식, 사건/쌍/장면의 다른 단위를 복원. 미복원 생성 이력 및 인간 전문성·교육·합의 절차는 채워 넣지 않음.
- 04-problem.tex: A 시작-유지-해제-행동 연결, 최초 모순/근거 부족의 별도 기록과 보조 P5 수식을 보강. P4를 입력 일관성 오류에 합치거나 미상을 확정 모순으로 분류한 과거 표현은 복원하지 않음.
- 05-method.tex: 단계별 입력 정리·프레임·실행·원문 회수와 파이프라인을 복원. 기존6상태와 보완2위치/배열을 구분하고 실제 XML의 Run/Done 도식으로 대체. 원문의 보조 시간 모델 네트워크를 중심 모델로 재사용하지 않음. 실제 배열·증거·질의 결과·사건/의무/원문 회수까지 추가. idx++가 전이에서 수행됨을 의사코드와 일치시킴.
- 06-experiments.tex: 간격은 사건 수임을 설명하고 각 변형이 검증하는 조건 관계, 세 분류/최초 위치/108개 문제 추적의 다른 분모를 보강. 기존40쌍 사전 선별 한계, 프레임/자동 경로와 최초/재시험 구분 유지.
- 07-results.tex: 기존40쌍에서의 P1/P4 기억 차이 해석, 간격별 창 효과, 전체 이력으로도 남는 실패, 복수 의무·대기 미상의 실패 메커니즘과 보완 설계를 연결. κ의 우연 일치 보정과 원 판정 단위를 설명. 기존표14는3행2/7/18요약; 상세27행은R3-11로 이동. 잘못된58건 전체 설정 의존 해석과 자연 모순/안전 정답 주장은 복원하지 않음.
- 08-discussion.tex: 검토 기록을 문장 수정/근거 보충/조건 연결 점검에 사용하는 절차와 출처·설정·모델·원문 기록 보존을 복원. 자동 채택/삭제 또는 학습 성능 개선을 입증한 표현은 사용하지 않음.
- 09-threats.tex: 기존 한계는 유지하고 잘못된 조건 연결의 의미 검토와 상태 속성 검사를 구분. 인간 독립gold/객체 해제/차량 안전 등의 미수행 사실 유지.
- 10-conclusion.tex: E6의 기여와 수치·주장 제한 유지. 방법/해석 보강과 정렬하며 과도한 일반 필요성·정확도 우위·자연 성능 주장을 복원하지 않음.
