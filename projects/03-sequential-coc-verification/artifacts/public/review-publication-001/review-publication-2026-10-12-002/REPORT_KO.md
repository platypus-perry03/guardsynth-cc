상태: **준비·검증 완료, 커밋·푸시 전**. 현재 원격 `review-artifact`는 기존 커밋 `79acd64`를 유지한다. 사용자에게 익명 범주 판정표의 공개 근거나 동의를 확보했다는 답변을 받은 뒤 추가본을 준비했다.

## 해석과 남는 결손

40쌍은 검사기를 이용해 기대 사후조건을 확인하는 회귀 자료다. 공개가 독립 검출 성능의 증거를 새로 만들지는 않는다. 검토 지침의 대기 상태와 A/B 두 양식 설명도 원문 그대로 보존했다. 이 문서를 네 검토자의 교육·합의 절차가 복원되었다는 근거로 쓰지 않는다.

실행별 생성 모델 버전, 생성 지시문·설정, 품질 점수 계산식·임계값은 여전히 복원 불가다. 검토자 자격·교육·합의 기록의 결손도 남는다. 자연 원문과 궤적을 배포하지 않으므로 공개 자료만으로 403→290 선별과 자연 자료 분석 전체를 재실행할 수는 없다. 따라서 R1-M6을 단순히 “완전 충족”으로 바꾸기보다, **보존·공개 가능한 자료를 추가 제공했고 미복원 항목과 재현 범위를 명시했다**고 답하는 편이 정확하다.

## 배포 후 반영할 문장

다음 문장은 브랜치 반영과 익명 미러 갱신·열람 확인 **후** 사용할 초안이며, 아직 원고나 답변서의 공개 완료 주장으로 반영하지 않았다.

- 원고 3.3절: “작성 시나리오와 40개 기준–변형 쌍, 검사 코드와 합성 사례 생성기, UPPAAL 모델과 질의, 실행 결과, 보존 검토 지침과 익명 범주 판정표 및 일치도 재계산 코드는 심사 기간에 익명 저장소로 제공하고 게재 시 공개한다. 원 CoC 문장, 영상과 자차 궤적은 원 배포처에서 확보해야 하며, 검토자 식별 정보·자유 메모·원 ID 대응은 제공하지 않는다.”
- R1-M6: “기존 144건·81건과 전수 대조 자료에 더해 40개 기준–변형 쌍과 생성기, 보존 검토 지침, 검토자 A–D와 장면 G01–G27의 익명 범주 판정표 및 κ·AC1 재계산 코드를 익명 저장소에 추가했습니다. 40쌍은 자연 문장 없이 구성한 합성 IR이며, 익명 판정표는 원 범주값만 보존하고 식별 정보·자유 메모·원 ID 대응을 제외했습니다. 공개된 자료에서 원 40쌍과 일치도 결과를 재현할 수 있습니다. 생성 모델의 실행별 버전, 원 생성 지시문·설정, 품질 점수 계산식·임계값은 복원할 수 없으며, 자연 자료의 완전한 재생성을 주장하지 않습니다.”

승인 후에는 **이 run의 `payload/` 내용만** 기존 `review-artifact` 브랜치에 반영한다. 저장소 전체 작업 트리나 원본 리뷰 CSV를 올리지 않는다. 익명 미러가 고정 커밋을 참조한다면 새 커밋으로 갱신하고 외부 열람을 확인해야 한다. 이전 run 001은 현재 배포본이므로 유지한다.
