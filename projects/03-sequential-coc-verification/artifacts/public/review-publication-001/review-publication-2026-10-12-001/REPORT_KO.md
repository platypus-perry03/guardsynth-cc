# 심사용 Git 공개 범위

공개 대상은 작성 144건·경계 81건·유한 전수 대조와 그 비교 코드, 모델, 질의, 기대 판정 및 결과다. 원 CoC·영상·궤적·개별 검토 기록·원고·답변서·심사 의견·기존 Git 이력은 제외한다.

`payload/`는 허용 목록으로 생성한 배포 결과다. 코드는 원래 실험 디렉터리가 유지보수 원본이며, 새 연구 구현을 이 경로에서 유지하지 않는다. 자연 자료 기반 결과의 완전 재현은 이 공개 범위에 포함하지 않는다.

같은 저장소의 `review-artifact` 브랜치에 부모 없는 최초 커밋으로 공개하고, 심사위원에게는 해당 브랜치의 고정 커밋을 가리키는 익명 미러 주소만 전달한다. 익명 서비스의 원 저장소 리다이렉트는 끈다. 서비스 로그인·익명 주소 발급 전에는 원고나 답변서에 공개 완료라고 쓰지 않는다.

## 재현 점검

공개 트리만으로 원 Python 비교 결과를 재현했고, 450개 사례 모델을 재생성해 보존 모델과 대조했다. 35,042,928개 전수 열거는 불일치 0건이며, 별도 처리 고장 5,256개 중 1,884개 불일치 기록도 그대로 재현했다. 포함된 행동 시험 26개와 내보내기 검사 4개가 통과했다. 실제 verifyta 재실행은 현재 라이선스 사용 불가로 완료하지 못했다. 기존 solver 결과를 새 실행 결과로 주장하지 않는다.

## Git 공개 및 익명 미러 설정

- 유지보수 원본은 기존 프로젝트의 실험 코드다. 심사용 브랜치는 자동 생성한 배포 트리이며 수정 원본을 이중 관리하지 않는다.
- 저장소: `https://github.com/jinkimh/guardsynth-cc` (설정용이며 심사위원에게 보내지 않는다).
- 공개 브랜치: `review-artifact`. 기존 main의 부모 이력을 포함하지 않는 최초 커밋 1개다.
- 고정 커밋: `79acd64a1fdf1f8b2c8a7817409368d976cd64f0`. 원격의 해당 브랜치 SHA와 일치함을 확인했다.
- [Anonymous GitHub 설정](https://anonymous.4open.science/anonymize)에서 사용자가 GitHub로 로그인한 뒤 위 저장소와 브랜치·커밋을 선택한다. 브랜치를 main으로 두지 않는다.
- 심사 기간에는 자동 갱신을 끄고 이 커밋을 고정한다. 수정할 때는 새 공개 트리를 검증한 후 브랜치를 갱신하고 익명 미러의 고정 커밋도 명시적으로 갱신한다.
- 원 저장소로의 리다이렉트는 사용하지 않는다. 만료 정책은 콘텐츠 삭제로 둔다. 이미지·PDF·외부 링크 노출도 끌 수 있으며 이 공개 트리는 해당 바이너리를 포함하지 않는다.
- 기본 계정·저장소 익명화 외에 작성자 성명·계정명·소속을 추가 익명화 대상으로 점검한다. 미러를 로그아웃 상태로 열어 파일·README·링크를 확인한 후 그 익명 URL만 논문/답변서에 사용한다.

현재 익명 미러 주소는 아직 발급하지 않았다. Git 브랜치 공개와 익명 링크 발급을 구분하며, 원고·답변서의 자료 공개 문장은 변경하지 않았다. 기존 공개 자료에 대한 검색 가능성이나 과거 노출은 이 새 브랜치로 소급 제거되지 않는다.

설정 근거: [공식 FAQ](https://anonymous.4open.science/faq), [공식 설정 구현의 브랜치/커밋 옵션](https://github.com/tdurieux/anonymous_github/blob/main/public/script/app.js).

HTTPS에서 심사용 브랜치만 새 임시 폴더에 복제한 뒤 동일한 기본 재현 절차를 다시 실행해 PASS를 확인했다. 개발 저장소의 원자료나 설치된 pandas에 의존하지 않는다.
