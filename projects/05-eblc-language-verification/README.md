# EBLC Language Verification

This project studies EBLC as an independent contract-language and verification contribution. It
owns the research question, comparative evaluation protocol, paper-specific experiments,
analyses, and manuscript. Reusable EBLC/BCV implementation remains in the
[`eblc-bcv` platform](../../platforms/eblc-bcv/).
