# 추가 학습 실험 데이터

- 상태: 데이터 생성·EBLC 행동 판정 대조 완료. 추가 학습은 아직 실행하지 않음.
- 학습 960 / 검증 240 / 시험 240건, 각각 P0/P1/P2 대응.
- 실제 고유 합성 이미지 60장. 숫자·후보 변형이며 실제 도로 장면이 아님.
- 학습 6.0–9.9초, 검증 10.0–10.9초, 시험 11.0–11.9초에 영역이 비워지는 설정.
- 대기시간 0.5/1.5초, 진입 후보 3패턴, 라벨 회전 4개. 경계는 표시 가능한 0.1초 단위.
- 원 실험 이미지 및 분할 간 이미지 중복 0. 같은 영상의 파생 계약·후보는 같은 분할 유지.
- 각 후보를 EBLC→Core→Z3에 바인딩해 독립 정수 환경 판정과 대조. SAT는 주어진 조건의 제약 준수이며 사실성·실차 안전성 보증이 아님.
- 최대 정상 진행 후보를 참조로 선택하므로 정지만 하는 답을 최적 답으로 처리하지 않음.
- P0는 계약 대기시간을 제공받지 않아 동일 입력에 다른 정답이 있을 수 있음. 영상 없이 후보·진행값만으로 풀 수 있는 단서와 단일 전환 가정도 한계로 유지.
- 기존 9개 checkpoint 결과에 합산하지 않음. 새 학습은 동일 예산·seed를 별도 동결한 뒤 실행.
