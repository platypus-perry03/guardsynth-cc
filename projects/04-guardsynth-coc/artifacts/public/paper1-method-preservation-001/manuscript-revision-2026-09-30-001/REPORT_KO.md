# GuardSynth 원고 통합 개정 및 검증

- 소유 프로젝트: `guardsynth-coc`
- 실행 ID: `manuscript-revision-2026-09-30-001`
- 범위: 원고 개정·통합·문서 검증. 새 학습 실행 및 실험 결과 변경 없음.

## 반영 내용

1. 사용자가 지정한 선행 원고 `projects/01-safety-constrained-coc/paper/manuscript/latex-kiee-review-2022-revision-v01`를 기준으로 선행 기여와 이번 기여를 구분했다. 선행 원고의 자연어 제약·생명주기·계약쌍·과제군을 이번의 최초 기여로 재주장하지 않는다. 출판 예정이라는 사용자 설명에 따라 게재지·연도·DOI는 추정하지 않았다.
2. 이번 기여는 **무슨 제약을, 어느 근거에서, 어떤 필드와 논리식으로 구성하여, 어떻게 CNL로 생성하고 원래 CoC에 넣는가**로 정리했다. JSON 자체와 의미론을 구분하고, EBLC가 일반 논리 언어보다 표현력이 우월하다는 미검증 주장은 하지 않는다.
3. 방법론에 여섯 과제의 **과제 → 제약 필드 → 실제 논리식 → 생성 CNL → 평가 판정** 연결 표를 넣었다. 관측·규칙·모델링 가정을 구분하고, 제약 삽입 위치와 정답/솔버 판정 비노출을 명시했다.
4. P0는 CoC만, P1은 우리 자연어 제약, P2는 EBLC·검증·CNL 개발 경로로 통일했다. 주 비교는 P1/P2 대 P0이며, P1–P2는 내부 개발 경로 비교다. CoC·EBLC 표기도 통일했다.
5. 제목·초록·서론·관련 연구·방법론·실험·논의·결론을 한글/영문으로 동기화했다. 핵심 결과는 본문에, 상세 조건·진단·기존 판정 기준은 부가자료에 두었다. 결과가 낮은 조건도 부가자료에서 보존했다.
6. 낡은 시간 과제 중심 `main.tex`를 통합 영문 원고로 교체하고 이전 소스는 `previous-main.tex`로 보존했다. 기존 완료 산출물은 덮어쓰지 않았다.

## 검증

- `verify_manuscript.py`: 실제 Core 조건 및 후보값에 대한 SMT 질의 16건이 저장된 판정과 일치.
- 본문 기본/미관측 조건 9행·수치 54개가 한글/영문과 원자료에서 일치.
- 부가자료 추가 조건 22행 및 5개 수치 제약 프로필의 실제 생성 CNL을 대조.
- 언어별 부가자료 S1–S10 존재 및 주요 용어 검사 통과.
- 동결 입력 파일의 검사 전후 SHA-256 일치. 새 학습 결과로 산입하지 않음.
- 통합 한글/영문 PDF 빌드 성공 및 `main.tex`와 생성 영문 소스 일치.
- 영문 첫 페이지와 한글/영문 핵심 대응 표를 이미지로 확인. 표 안의 논리식·CNL·판정이 읽히며 잘림은 확인되지 않았다.
- 파일 명명 검사에는 이번 변경의 오류가 없다. 저장소 전체에서는 기존 별도 프로젝트 디렉터리 1건, 기존 제출 파일 `(1)` 3건, 루트 `portal_exec.md` 1건이 남으며 이 작업에서 수정하지 않았다.

검증 원자료는 [content_checks.json](content_checks.json), 소스 해시는 [RUN_MANIFEST.json](RUN_MANIFEST.json), 최종 산출물 기록은 [RESULT.json](RESULT.json)에 있다.

## 해석과 남은 사항

- SAT는 선택 후보의 모델 내 적합성이지, 최적 행동이나 실차 안전성 보장이 아니다. 안전하지만 덜 진행하거나 미완료인 후보는 SAT이면서 정확도 오답일 수 있다.
- 수치 CNL은 Core의 미완료 후보에 대한 면제 조건을 별도 문장으로 완전히 표시하지 않는다. 따라서 완료 후보의 수치 조건 대응과 전체 계약의 독립 의미 동등성 증명을 구별하여 방법론에 명시했다.
- 정확도 평가와 SMT 검사는 구현이 나뉘어도 같은 과제 가정을 공유한다. 독립된 실제 도로 안전 검증으로 해석하지 않는다.
- 공식 영문 템플릿에는 첫 페이지 overfull 경고 2건(9.2679pt), 클래스 이름·색상 정의·Courier 폰트 대체 경고가 남는다. 컴파일 실패나 누락 문자 경고는 없으나, 제출 전 템플릿/폰트 정리는 필요하다.
- 저자·소속·연구비·약력·선행 논문 서지정보 및 관련 투고 공개 사항은 저자 확인 후 확정한다. AI 집필 지원 고지는 검토본에 포함했다.
- 현재 TeX는 로컬 절대 경로를 사용한다. 제출 시 클래스·그림·참고문헌을 포함한 이식 가능한 소스 묶음을 준비해야 한다.

문서 구성에는 `pages:write-page`, 완료 판단에는 `superpowers:verification-before-completion` 지침을 적용하여 기여/근거/한계를 분리하고 실제 검사 결과에 따라 완료 범위를 한정했다.
