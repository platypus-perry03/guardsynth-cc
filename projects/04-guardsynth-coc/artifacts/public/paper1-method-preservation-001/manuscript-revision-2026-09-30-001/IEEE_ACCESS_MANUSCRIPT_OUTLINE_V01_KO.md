# IEEE Access 원고 구성

현재 통합 저자 검토본의 구성을 기록한다. 제목·초록은 [해당 원문](IEEE_ACCESS_TITLE_ABSTRACT_V01_KO.md), 전체 PDF는 [통합 원고](../../../public/paper1-method-preservation-001/manuscript-revision-2026-09-30-001/ieee-access-manuscript-ko.pdf)를 참조한다.

## 핵심 기여

CoC·장면 근거·공급 규칙에서 필요한 제약 내용을 선택하고 관측·가정을 구분하여 EBLC 필드에 연결한다. 제한된 논리 검증 뒤 CNL을 생성하여 원래 CoC에 추가한다. 본문은 **과제 → 제약 필드 → 실제 논리식 → 생성 CNL → 평가 판정**의 연결을 유지한다.

선행 Safety-Constrained CoC 원고는 자연어 가드·생명주기 요소·계약쌍 평가·정적/시간/기동 과제군을 이미 제공한다. 이번 논문은 출처–명세–CNL 개발 경로와 지원 검사를 추가한다. 재사용한 과제 원리와 새로 실행한 실험은 구분한다.

## 섹션별 역할

| 섹션 | 내용 | 근거 |
|---|---|---|
| I 서론 | 배경, CoC의 한계, 선행/현재 기여 구분 | 지정된 선행 원고와 현재 여섯 과제 결과 |
| II 관련 연구 | 주행 추론, 규칙 논리, 언어 정형화 | 원 논문; 확인하지 않은 기능 부재 주장 제외 |
| III 배경 | CoC/VLM·SMT·CNL·LoRA의 기존 개념 | 기존 이론만 기술 |
| IV 제안 방법 | 입력, EBLC 의미론·선택 이유, 출처–필드 추출, 검증, CNL 삽입, 과제–판정 대응 | 실행 프로파일·생성 조항·경계 질의 |
| V 실험 설정 | P0/P1/P2, 데이터, 예산, 참조 규칙, 지표 | 과제군 내 설정 통제 |
| VI 결과 | 여섯 과제, 계약쌍, 교란, 명세 오류, 미학습 수치 | 고정된 실제 결과 |
| VII 논의 | 기여, 정보 조건, 근거/논리/행동 구분, 한계 | 검증 자체의 인과적 성능 주장과 구별 |
| VIII 결론 | 방법론 기여와 실험 범위 | 새 주장 추가 없음 |

## 비교와 범위

P0는 CoC 단독, P1은 우리의 기존 자연어 제약 추가, P2는 우리의 EBLC 생성 CNL 추가이다. P1·P2에는 학습과 평가 모두 제약을 제공한다. 둘의 비교는 내부 표현·개발 경로 비교이며 P0 대비 효과는 추가 정보 제공의 효과를 포함한다. 정형적 비열등성이나 P2의 보편적 우월성을 주장하지 않는다.

지원 명세 오류 주입은 품질 평가로 포함한다. 별도 EBLC 테스트 생성·실행 감시 시스템은 이 논문의 기여가 아니다. 시드·구간·표현 변경·복합 조건·영상 개입·비용 학습·기존 운영 기준은 부가자료에 배치하고 유리하거나 불리한 현재 결과를 모두 보존한다.

영문 통합본은 공식 IEEE Access 템플릿을 사용하고 한글본은 2단 검토용으로 제공한다. 저자 정보와 선행 원고 출판 서지는 저자 확인 후 완성한다.
