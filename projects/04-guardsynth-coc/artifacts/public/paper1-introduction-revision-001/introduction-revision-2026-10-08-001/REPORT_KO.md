# 최종 서론 확인 및 영어 원고 교체

- 프로젝트: `guardsynth-coc`
- 날짜: 2026-10-08
- 요청: 첨부한 한글 최종 서론의 하단 확인 항목을 검증한 뒤 영어 원고와 PDF에 반영.

## 확인 결과

1. **평균 위치 차이:** 원본 CSV를 재집계했다. 입력·규칙 제공 경로별 세 seed 평균의 최댓값은 0.0867759039m이다. 개별 예측 쌍의 평균 최댓값은 0.0962032676m이므로, 서론의 0.09m 기준은 세 seed 평균에 한정했다.
2. **모델 관계:** Alpamayo-R1은 Alpamayo 1이라고도 불린다. 공식 모델 설명에서 Alpamayo 1.5는 같은 계열의 후속 버전이다. 인용 연구의 1.5와 이번 사전 실험의 R1을 동일 모델로 취급하지 않았다.
3. **보충자료:** 기존 S1–S10을 유지하고 S11에 R1 사전 진단, S12에 위치 유지 후보 선택 학습을 추가했다. 제한 원자료의 일반적인 공개 허가를 확인한 것은 아니다. 원본 영상·이미지·좌표 궤적·전체 CoC 출력은 보충자료에 넣지 않고, 절차와 집계 수치만 정리했다.
4. **문장 변화 결과:** static 과제 P2의 정확도 100%→80.32%, 즉 19.68%p 하락을 명시했다. 모든 진단의 최대 하락이라는 표현은 사용하지 않았다.

선행 연구에도 typed guard 검사가 있었으므로, 이를 검사하지 않은 연구로 서술하지 않았다. 이번 논문의 차별점은 가드의 근거·수치·해제 조건을 구성하고 명세/검사/CNL로 연결하는 개발 절차로 기술했다. 자연어가 본질적으로 근거를 구분하지 못한다거나 모든 VLM 입력이 자연어여야 한다는 일반화도 피했다.
