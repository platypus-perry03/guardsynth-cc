- 상위: [연구계획](../plans/01_RESEARCH_PLAN_V02.md), [범위 결정](../decisions/PAPER1_METHOD_PRESERVATION_AND_LABELING_DECISION_V01.md)

## 1. 목적과 동결

사용자 후속 명확화에 따라 검증의 목표는 모델 성능의 추가 향상이 아니라 CoC에 삽입하는 제약의
품질 관리다. D1–D3은 기존 학습 효과의 보존·강건성·영상 의존성을, D4는 제약의 오류 탐지와 차단을
각각 평가한다. CoC 전체의 사실성을 보증하거나 SAT 성공으로 근거 대응·CNL 의미 보존을 대신하지 않는다.
주입 오류 탐지 결과를 자연 발생 CoC 오류율 개선으로 일반화하지 않는다.

완료한 temporal-learning-2026-09-29-001의 P0/P1/P2 ×3 seeds,9개 adapter를 변경 없이 재사용한다.
기존 표준 성능을 본 뒤 설계한 후속 진단이며 기존 사전등록 시험으로 재표기하지 않는다.
새 protocol/run ID에 평가 조건·표본 수·생성 seed·입력·checkpoint 해시·분석을 첫 새 예측 전에
고정한다. 좋은 결과만 선별하거나 새 평가 결과로 prompt/threshold/renderer를 조정하지 않는다.
실패 후 수정은 새 버전과 별도 개발 자료를 사용한다. 기존4개 완료 run 및 Project01은 불변이다.

## 2. 최소 확장 묶음

### 사용자 후속 요청: 추가 학습 자료부터 생성

`temporal-training-data-2026-09-29-001`은 기존 checkpoint를 평가하는 D1–D4와 별도의 새 학습 준비 자료다.
학습 clear 시각6.0–9.9초, validation10.0–10.9초, test11.0–11.9초로 영상 파생군을 분리했다.
0.5/1.5초 계약, 후보3패턴, 라벨4회전을 조합하여 split별960/240/240 paired rows를 생성했다.
P0/P1/P2 각각 같은 장면·정답을 제공한다. 고유 영상은40/10/10장이며 장면 수를 조합 행 수로 부풀리지 않는다.
기존 및 D1–D4 시험 자료를 학습으로 편입하지 않는다. 이 새 자료의 test도 학습·prompt 조정에 사용하지 않는다.
실제 비교 학습의 예산·seed·성공 기준은 별도 실행 전에 고정해야 하며 데이터 준비가 가중치 갱신 완료는 아니다.

EBLC는 명세 자체의 검증뿐 아니라 행동 테스트 기준으로 사용한다. 선택 후보의 진입 여부·시각과
장면 clear 시각을 Core에 바인딩한 실행 판정을 독립 환경 규칙과 대조한다. 새 데이터의 모든 후보에
대해5,760건 일치를 확인했다. 정지의 SAT 판정과 정상 진행 목표 달성은 구별한다.
참조 정답은 독립 환경의 허용 후보 중 최대 진행값으로 정하며 CNL/모델 예측에서 역생성하지 않는다.

| ID | 실험 | 통제 | 확인할 주장 |
|---|---|---|---|
| D1 | 새로운 clear 시각·대기시간 및 경계 후보 | clear만 변경/대기시간만 변경/조합을 분리, candidate label 회전 | 같은 숫자/후보 패턴 밖에서의 행동 선택 |
| D2 | 같은 제약의 의미 보존 paraphrase | 장면·수치·정답 고정, P1/P2에 같은 변형 연산, P0 중복은 새 독립 표본으로 세지 않음 | 표현 변화 강건성 |
| D3 | 원본 영상/빈 영상/다른 clear 시각 영상 | 문장·후보 고정, 모순 입력과 결측 입력을 별도 표시 | 영상 의존성 진단, text/candidate shortcut 가능성 |
| D4 | 잘못된 제약 주입과 검증 적용/생략 | 같은 source·후보 쌍, 정상 계약 포함, 오류 종류 사전 고정 | 검증 단계의 scoped 탐지·차단·coverage |

D1은 기존6장 이미지와 겹치지 않는 clear 시간값을 포함한다. 실제 고유 pixel/semantic 입력 수,
학습과의 중복, candidate permutation을 보고한다. 단순 색상/label 회전 증가는 독립 환경이 아니다.
clear 시간과 candidate 설명이 만드는 산술 단서도 공개한다. 단일 clear 전환·재점유 없음 가정은 유지한다.
현재 bridge의 duration allowlist를 몰래 확장하지 않고 별도 profile/version의 수치 범위/단위와
source-only 변환을 검사한다. 모델 입력에 표시한 정밀도보다 작은 경계 차이를 구분하라고 요구하지 않는다.
밀리초 SMT 경계 검사는 모델의1자리 소수 프롬프트 평가와 별도다.

D2는 부정·최소 대기·대상·조건을 보존한 고정 문구만 사용한다. 프로그램 필드 대응 검사와
검토 필요 여부를 기록하고 LLM paraphrase를 쓰면 raw 응답/모델/prompt를 보존한다.
문구 차이로 의미가 달라진 사례는 robustness 성공/실패에 몰래 섞지 않는다.

D3는 정상 입력의 성능과 분리한 개입이다. swap은 어떤 판단 관련 시각 정보를 바꿨는지 명시한다.
기존 정답에 대한 선택 변화와 이미지가 암시하는 별도 조건을 구분하고, 모순/빈 영상의 출력 감소를
실제 도로 오류율로 해석하지 않는다. 영상 개입에 변화가 없으면 그 결과도 그대로 보고한다.

D4는 threshold 변조·비교 방향 반전·필수 조건 삭제·단위 오류 등 지원하는 오류를 사용한다.
schema/source-field 거부, Core/SMT 탐지, CNL 의미 불일치, 미탐지를 분리 집계한다.
독립 환경 규칙/evaluator로 source 의미를 대조한다. 내부적으로 일관된 잘못된 규칙을 SAT만으로
검출했다고 하지 않는다. 정상 계약의 오탐/수용 coverage도 기록하여 전부 거부하는 해법을 막는다.
‘검증 때문에 VLM 성능이 향상됐다’는 인과 주장은 이번 연구의 목표가 아니다. 별도 검증 유무 학습
ablation은 완료 조건이 아니며, 동일 후보 집합의 검증 전후 제약 품질을 주된 검증 기여로 보고한다.

## 3. 실행·분석

먼저 데이터 생성·고유성·정답·경계·해시·양성/음성 회귀 검사를 CPU에서 수행한다.
P0/P1/P2 모두 동일 조건으로 평가하며 기존9개 checkpoint를 다시 학습하지 않는다.
예측 전 고정한 작은 균형 묶음으로 시작하고, 실행 중 성공 장면만 골라 표본을 늘리지 않는다.
학습 라벨/모델 예측을 독립 evaluator 입력으로 사용하지 않는다. 답변 불가/잘못된 토큰은 coverage와
실패 분모에 남긴다. 위반·제약 준수 목표 완료·deadlock·정확도·계약쌍·출력 변화와 seed/semantic-group
불확실성을 보고한다. 반복되는 template가 표본 수를 부풀리지 않도록 paired 그룹을 유지한다.

다른 사용자 GPU를 중단하지 않는다. 로컬 사용 가능한 GPU에서 평가하고 자원 대기 중에도
D4/데이터 검증/원고 작업을 수행한다. 완료 결과를 새 owner-scoped run과 원고 후속 snapshot에 저장한다.
대규모 재학습·새 도로 설문·다중 maneuver/재점유 모델은 이번 최소 확장의 선행조건이 아니다.
