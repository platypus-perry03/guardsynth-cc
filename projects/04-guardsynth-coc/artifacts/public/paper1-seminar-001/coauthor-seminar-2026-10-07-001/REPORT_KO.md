# GuardSynth 공저자 세미나 빌드 검증

- 소유 프로젝트: `guardsynth-coc`
- 현재 영어 원고와 기존 실험 결과를 바탕으로 한 한국어 16:9 Beamer 자료.
- 본 발표 24장: 설명 27분, 공저자 논의 3분. 보충 6장은 선택 사용.
- 발표용 PDF와 발표자 메모 PDF 각각 30페이지. 모든 메모에 설명 포인트와 권장 시간이 포함됨.
- 핵심 흐름: 역할 구분 → 근거와 EBLC → 검증 성질 → CNL/CoC → 비교 조건·평가 → 결과·한계 → 공저자 논의.

## 확인 결과

XeLaTeX를 두 번씩 실행하여 두 PDF를 빌드했다. 내용 넘침, 누락 글자, 미정의 참조가 없다. 30장 전체의 렌더링과 발표 메모를 확인하고, 흐름도·수식·주요 표·그래프를 확대 점검했다. 표 뒤 문장이 같은 줄에 붙던 배치와 그래프 수치 라벨 간격을 수정했다.

주 결과 36개 수치, 미학습 조건 18개 수치, 데이터 규모, 계약 쌍 정확도·셔플링·문장 변형 수치를 원고와 대조했다. 파일 해시로 입력 원고와 실험 문서의 보존을 확인했다. 새 학습·추론·레이블링은 수행하지 않았다.

파일 이름 검사는 실행했으며, 새 세미나 파일 관련 지적은 없다. 저장소 전체 검사에는 이전부터 존재하던 무관한 10개 이름 문제만 남아 있다.

## 재현

정본 소스와 빌드 방법은 `projects/04-guardsynth-coc/paper/seminar/`에 있다. 이 환경의 PGF/PGFPlots는 기존 로컬 TeX 자료를 `/tmp/guardsynth-seminar-texdeps/tex/`로 복사해 사용했다. 실제 TEXINPUTS, 입력 SHA-256, PDF SHA-256, 페이지 수, 시간 배분은 `RUN_MANIFEST.json`에 기록했다. 완료된 실행은 보존하며 재빌드에는 새 run ID를 사용한다.

이 발표의 시간 배분은 권장 진행표이며 실제 발표 속도에 따라 조정할 수 있다. Safety는 명세 모델 안의 반례 배제이며, 해제 이후 SAT는 진입 가능성으로 설명한다. Liveness, 실제 도로 안전, 모든 표현에 대한 일반화나 P2의 일관된 성능 우위는 주장하지 않는다.
