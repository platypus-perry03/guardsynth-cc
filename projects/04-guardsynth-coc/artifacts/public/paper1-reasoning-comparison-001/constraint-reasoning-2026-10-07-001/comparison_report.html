Constraint-aware reasoning on existing P1 checkpoints

P1 + ZS-CoT adds the original Zero-Shot Chain-of-Thought instruction and two-stage answer extraction. P1 + PS adds the basic Plan-and-Solve instruction and native conditional answer extraction. Both reuse each existing P1 LoRA checkpoint, image, CoC, supplied natural-language rule and candidate descriptions. No new training or labels are created.

Each procedure scores 240 temporal, 144 static and 96 maneuver test rows for each of three seeds (42, 17, 123): 2,880 new predictions. P1 and P2 are archived baselines on the same rows, rule semantics, candidates and references. P2 has its own CNL representation and checkpoint. The two prompt procedures remain transferred adaptations, not original-paper model reproductions.

This comparison tests inference-time prompting given the supplied rules. It does not isolate a causal effect of verification, reproduce DriveLM/DriveVLM, or establish real-road driving safety. The synthetic test images and numeric candidates are unchanged. Native reasoning token caps differ, so inference cost is reported rather than assumed equal.

Observed behavior matters: all temporal and maneuver first-stage outputs were single candidate labels, despite the reasoning instructions. Static outputs frequently reached the reasoning-token cap: 335/432 ZS-CoT and 323/432 PS generations. Thus the observed scores describe prompting existing label-trained checkpoints under these generation limits; they are not a general ranking of fully realized reasoning methods. P2 does not lead on every task: both prompting controls reached 100% lane-change accuracy, compared with 97.92% for P2.
