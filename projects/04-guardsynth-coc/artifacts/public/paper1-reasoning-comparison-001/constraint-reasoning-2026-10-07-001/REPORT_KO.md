# 동일 규칙 정보를 제공한 추론 프롬프트 비교

- 소유 프로젝트: `guardsynth-coc`
- 실행 ID: `constraint-reasoning-2026-10-07-001`
- 상태: 완료
- 목적: 기존 P1 체크포인트에 추론 프롬프트를 추가했을 때 행동 후보 선택이 개선되는지 확인한다. 기존의 규칙 없는 P0 비교와 달리, 모든 비교 조건에 동일한 제약 규칙의 의미를 제공한다.

## 비교 조건과 평가 규모

| 조건 | 입력과 실행 방식 |
|---|---|
| P1 | 기존 CoC와 자연어 제약을 제공한 기존 평가 결과 |
| P1 + ZS-CoT | 같은 P1 체크포인트와 입력에 원래 Zero-Shot CoT 지시문 및 두 단계 답 추출을 적용 |
| P1 + PS | 같은 P1 체크포인트와 입력에 기본 Plan-and-Solve 지시문 및 원래의 조건부 답 추출을 적용 |
| P2 | 같은 규칙을 EBLC 유래 CNL로 제공한 기존 P2 체크포인트의 평가 결과 |

새 학습, 새 사람 주석, 새 장면을 만들지 않았다. 학습 seed 42, 17, 123의 기존 어댑터와 고정된 테스트셋을 사용했다. 각 방법·seed에서 시간 과제 240행, 정적 과제 144행, 기동 과제 96행을 평가했다. 두 추가 방법의 새 예측은 총 **2,880개**다. P1과 P2의 기존 예측도 같은 평가 기준으로 다시 집계했다.

행 수는 독립적인 도로 장면 수가 아니다. 기동 과제의 동일 이미지·텍스트 입력은 중복 추론을 제거한 뒤 원래 평가 행으로 복원했다. 실제 원시 생성 기록은 2,760개다. P1과 P2의 행 ID, 이미지, 후보, 기준 정답 및 허용 후보 집합을 확인했으며, 정답·검증 판정 등의 메타데이터는 모델 입력에 넣지 않았다.

## 결과

480개 평가 행을 기준으로 계산한 지표의 세 seed 평균이다. 과제별 단순 평균이 아니라 행 수로 가중한 전체 결과다. 계약 쌍 정확도는 쌍 수로 가중했다.

| 조건 | 정확도 (%) | 확인된 위반율 (%) | 계약 쌍 정확도 (%) | 무효 응답률 (%) |
|---|---:|---:|---:|---:|
| P1 | 98.40 | 0.69 | 96.81 | 0.00 |
| P1 + ZS-CoT | 94.24 | 2.57 | 88.89 | 0.97 |
| P1 + PS | 94.17 | 3.54 | 88.89 | 1.18 |
| P2 | 98.82 | 0.42 | 97.64 | 0.00 |

정확도는 허용 후보 중 진행 점수가 가장 높은 기준 정답과 일치하는지를 측정한다. 위반율은 전체 평가 행 중 금지된 후보를 선택한 비율이다. 무효 응답의 허용 여부는 알 수 없으므로 안전한 응답으로 해석하지 않으며, 정확도 계산에서는 오답으로 포함한다. 계약 쌍 정확도는 같은 장면·후보에 서로 다른 규칙을 적용한 두 사례 모두를 맞혀야 성공으로 센다.

| 과제 | P1 정확도 | P1 + ZS-CoT 정확도 | P1 + PS 정확도 | P2 정확도 |
|---|---:|---:|---:|---:|
| 시간 대기 | 96.81 | 95.97 | 97.08 | 98.06 |
| 최대 속도 | 100.00 | 79.86 | 88.19 | 100.00 |
| 장애물 이격 | 100.00 | 84.03 | 81.25 | 100.00 |
| 진입 지연 | 100.00 | 98.61 | 86.81 | 100.00 |
| 정지 | 100.00 | 100.00 | 100.00 | 100.00 |
| 차선 변경 | 100.00 | 100.00 | 100.00 | 97.92 |

전체 평균에서는 두 추론 프롬프트가 기존 P1보다 낮은 정확도를 보였다. 그러나 P2가 모든 과제에서 앞선 것은 아니다. 시간 과제에서는 PS가 P1보다 약간 높았고, 차선 변경에서는 P1과 두 프롬프트 조건이 P2보다 높았다. 통계적 유의성이나 일반적인 방법 우열을 주장하지 않는다.

## 출력 행동과 해석의 한계

시간·기동 과제에서는 두 방법 모두 첫 단계에서 추론 과정 대신 후보 문자만 출력했다. 따라서 해당 과제의 결과를 실제 다단계 추론 수행의 증거로 사용할 수 없다. 기존 어댑터는 후보 문자 출력으로 학습되어 있다.

정적 과제에서는 ZS-CoT의 432개 생성 중 335개, PS의 432개 생성 중 323개가 첫 단계 토큰 한도에 도달했다. 생성 토큰 수는 두 단계 합계이며 특수 토큰을 제외한다. 정적 과제의 평균 생성량은 ZS-CoT 약 124.41토큰, PS 약 235.38토큰이었다. 시간·기동 과제는 두 단계 합계 평균 2토큰이었다.

ZS-CoT 첫 단계 한도는 128토큰, 기본 PS는 256토큰, 최종 답 추출은 각각 32토큰이다. 원래 절차의 지시문과 추출 방식을 유지했으나, 현재 체크포인트와 객관식 과제에 적용한 비교이므로 원 논문의 전체 재현 실험은 아니다. 특히 긴 응답의 잘림과 답 추출 실패가 영향을 줄 수 있다. 두 방법의 추론 비용을 동일하다고 가정하지 않는다.

이 실험이 뒷받침하는 결론은 **규칙 정보를 동일하게 제공하더라도, 현재의 후보 문자 학습 체크포인트에 추론 지시문을 추가하는 것만으로는 전체 선택 성능이 개선되지 않았다**는 것이다. EBLC 검증 자체의 인과적 학습 효과, 다른 추론 방법 전반에 대한 우수성, DriveLM·DriveVLM 대비 성능 또는 실제 도로 안전성을 입증하지 않는다. 입력 영상과 합성 후보 수치의 기존 한계도 유지된다.

## 재현 기록과 검사

정적 과제의 마지막 작업이 사용자 턴 중단으로 종료되어, 저장된 80개 원시 출력을 보존하고 남은 64개 입력만 재개했다. 체크포인트·프롬프트·탐욕적 디코딩·배치 크기·토큰 한도는 동일하다. 기록된 시간은 완료되어 저장된 배치의 생성 시간이며, 저장되지 않은 중단 작업 시간과 모델 준비 시간은 포함하지 않는다. 정적 작업 전체의 연속 wall time은 복원할 수 없다.

- 2,880개 예측을 원래 후보 규칙으로 다시 계산하고, 2,760개 원시 생성의 입력·답 추출·예측 연결을 확인했다.
- 동결된 입력·소스·체크포인트 관련 해시 70개가 일치한다. 이전 P0 비교 산출물 62개는 변경되지 않았다.
- 관련 단위 검사 6개 통과, `git diff --check` 통과.
- 파일 이름 검사는 실행했으며 기존의 무관한 위반 10개를 보고했다. 이번 비교의 새 파일은 위반 목록에 없다.
