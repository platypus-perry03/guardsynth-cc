# 규칙 정보를 제공한 일곱 조건 비교

- 소유 프로젝트: `guardsynth-coc`
- 상태: 완료
- 새 예측: 4,320개; 기존 네 조건과 합쳐 10,080개 예측 비교
- 기존 테스트 480행 × 학습 seed 3개 × 조건 7개; 독립 영상 수가 아니다.
- 새 학습·사람 주석 없음

P0 + 규칙은 CoC만으로 학습한 P0 체크포인트에 평가 때만 P1의 규칙 포함 입력을 제공한 조건이다. P1은 학습·평가 때 규칙을 제공했고, P2는 같은 규칙을 EBLC 유래 CNL로 제공했다. ZS-CoT와 기본 PS는 각 체크포인트에 추론 지시 및 원래 답 추출 절차만 추가한다.

P0 + 규칙과 P1을 비교하면 기존 체크포인트의 규칙 포함 학습과 평가 시 규칙 제공을 구분할 수 있다. 각 계열 내부의 직접 답변과 추론 프롬프트 조건은 추론 지시의 추가 효과를 비교한다. 다만 P0는 학습 당시 규칙 없이 규칙별 정답을 학습했으므로, 이를 일반적인 순수 학습 효과 추정으로 확대할 수 없다. P2는 표현과 체크포인트도 다르며 검증 자체의 인과적 효과는 분리되지 않는다.

원시 응답에서 실제 추론이 생성됐는지 확인해야 한다. 첫 단계가 문자 답만 출력한 경우 다단계 추론을 수행했다고 해석하지 않는다. ZS-CoT/PS의 한도는 128/256토큰, 최종 답 추출은 32토큰, 직접 답변은 12토큰이다. 긴 응답의 잘림과 무효 응답을 별도 보고하며, 무효 응답의 허용 여부는 미확인이다.
