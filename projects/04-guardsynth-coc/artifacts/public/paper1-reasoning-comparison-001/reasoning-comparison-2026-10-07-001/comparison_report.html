Reasoning-prompt comparison on the existing P0 checkpoints

Two supplementary inference controls use the existing Qwen3-VL-2B-Instruct P0 LoRA checkpoints. Zero-shot CoT uses the original step-by-step trigger and two-stage extraction. Basic Plan-and-Solve uses prompt_201 and its conditional extraction procedure. Neither receives an added constraint. There is no additional training or manual labeling.

Each method is scored on 480 primary test rows for each of three optimization seeds (42, 17, 123): 2,880 scored predictions in total. Deterministic outputs are reused for identical image-and-text inputs within the same checkpoint/method. This produces 1,092 unique first-stage inference cases. Archived P0/P1/P2 test predictions provide the reference comparison.

Interpretation boundary. These are transfers of prompting procedures to our VLM task, not reproductions of the original GPT-3 experiments or of DriveLM/DriveVLM. P1/P2 receive rule information that the reasoning controls do not. Every identical P0 input group has conflicting target labels, giving a 50% fixed-output accuracy ceiling. Therefore, the comparison does not establish equal-information algorithm superiority.
